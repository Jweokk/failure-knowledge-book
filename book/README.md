**英文版翻译进行中**：`en/` 目录。方法为独立成文（非逐字翻译），事实层语言中立。翻译状态见 `en/TRANSLATION_STATUS.md`。

## 对提纲 v0.2 的修订记录

按作者要求，本稿不把 v0.2 当成不可动的合同。修订如下：

1. 二十四章机制与二十四词机制词表一一对应，一章一词，不并章不加章。词表与案例采集库共用，保证"机制名→案例编号"全程可检索。
2. 每个机制章骨架在"自检五问"前新增一小节：与相邻机制的边界。每章点名两三个最容易混淆的邻章机制，各给一句区分判据。这是验收闸 4（机制不越界）的固定阵地。
3. 案例卡十二字段定为：1 编号｜2 一句话事由｜3 主体｜4 时间与地点｜5 领域与机制｜6 当时可见｜7 被排除的选项｜8 决策点｜9 不可逆点｜10 后果量级｜11 最小反事实｜12 证据等级与出处。v0.2 提到的第 6、7、11 三项正好落在"当时可见、被排除的选项、最小反事实"上，编号从此全书不漂移。
4. 新增附录 E：机制家系。记录哪些机制常成对出现（如"程序漂移×安全边际被吃掉"、"监管滞后与俘获×合规但不安全"）、互相伪装时怎么分辨。机制章末尾的"边界"小节与附录 E 互链。
5. 新增附录 C 的固定格式：每个领域给"三个入口库、一条查询语法示例、一个反爬提示"，与第四部领域页的"记录质量"栏互链。
6. 停点标记统一为 `〔停点：读者先判断，翻页再看〕`，后接三个问题，再接 `〔结局〕`。案例第一行标注编号，编号规则与附录 B 一致（`领域代码-序号`）。
7. 字数上限全部忽略（作者 2026-10-31 指示）。写全写深，超出 v0.2 的部分在章末标注实际字数即可。
8. 双语执行口径：第一稿以中文叙述层单独成文（不译英文案例的原生叙述），事实层的数字、日期、机构名、文书标题保留原文语言；英文版案例卡留待第二稿。
