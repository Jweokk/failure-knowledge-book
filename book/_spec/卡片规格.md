# 案例卡片规格（写作执行方必读）

一本书《失效》。体例：机制为主，案例只写当事人在当时可见的信息。你要做的是把一章里"压缩案例"扩成"完整卡片"。

## 一、卡片结构（12 项，缺一项即退）

```
### 案例N（领域）：标题

编号（如 av-031）。

**时间与地点**：

**主体**：

**事发前在做什么**：

**决策点**：

**当时可见**：

〔停点：读者先判断，翻页再看〕

你现在坐在这个位置上，手上是上面这些材料。

1. 你会怎么做？（写下具体动作，不要写"更重视"）
2. 这些材料里，哪一条最可能被你忽略？为什么它看起来不重要？
3. 如果只允许你设一个检查点，设在什么时候、检查什么？

〔结局〕……

**被排除的选项**：

**早期信号**：

**加码点**：

**失效链**：

**最小反事实**：

**结局与来源**：
```

## 二、每项写什么、写多少

| 项 | 汉字 | 要求 |
|---|---|---|
| 时间与地点 | 60–120 | 日期精确到日；地点写到设施/会议室层级 |
| 主体 | 100–180 | 机构全称＋当事部门；责任主体写岗位不写人 |
| 事发前在做什么 | 350–450 | 出事前正在推进的**具体动作**（投产、放量、检修、评审、改型）。不是公司简介，不是行业背景 |
| 决策点 | 500–700 | 2–4 个不可逆时刻，每个给日期＋场合（会议/文件）＋签字人。写"管理层决定"而不给时间载体＝不合格 |
| 当时可见 | 450–650 | 只写当事人在当时手上真有的东西：影像、纪要、邮件、读数、报告。每条带日期。**另起一句写"事后才知道的信息"** |
| 停点 | 固定 | 三问一字不改，见上。不许加第四问 |
| 结局 | 300–400 | 伤亡/损失/处罚的数字；并把三问回看一遍：第一个问题最常见的答案是什么，本案里这个动作的成本是什么 |
| 被排除的选项 | 300–400 | 当时考虑过什么、以什么理由否掉。至少 3 个 |
| 早期信号 | 350–500 | 3–5 条，每条写"信号＋被什么理由压过去"。信号要具体到某个日期某个文件 |
| 加码点 | 300–400 | 从"出了点问题"到"不能回头"的那一步：日期＋动作＋谁批的 |
| 失效链 | 400–550 | 技术层／组织层／激励层**分开写**，最后一句写交界处断在哪 |
| 最小反事实 | 250–350 | **只写一个动作**，必须当时可做、不靠运气。写"如果当初更重视安全"＝不合格 |
| 结局与来源 | 200–300 | 一手来源全题录＋链接编号（如"链接见附录 B av-031"） |

单卡合计 3,000–3,600 汉字。宁少勿凑：写不满就说明材料没挖到，回去读报告。

## 三、五条纪律

1. **只写当时可见。** 判断标准：当事人当天能不能在桌上看到这份东西。看不见的（残骸分析、事后调查结论、事故后的追责）一律放到"事后才知道的信息"。
2. **不写内心动机。** 只写行为、文件、会议、签字。不许出现"他认为""他担心""出于侥幸"。他担不担心，你不知道；他签没签，报告里有。
3. **每个数字都要能回到原文。** 格式：`（报告简称 p.页码）`。页码用 PDF 页码。核不到的数字，删掉，不要估。
4. **不做道德评价。** 不写"这反映了""本质上是""说明了"。机制解释留给章里的第 1、2、5 节。
5. **语感。** 短句为主，忌排比，忌比喻链（一段末抛一个比喻、下段接住它）。禁用"不是……而是……"（每卡最多 1 次）、"首先/其次/最后"开头、"值得注意的是""由此可见"、感叹号。

## 四、怎么拿到事实

1. 先读本章 §3 现有的压缩案例——它已写明编号、来源、核心事实，是骨架。
2. 打开附录 B 里该编号的链接，下载一手报告（PDF 直接 `curl -L -A 'Mozilla/5.0' -o x.pdf`，再 `pdftotext`）。
3. 在报告里定位：决策会议、日期、签字、告警记录、检验报告、邮件。**读到原文再写，不要凭印象补。**
4. 报告读不到（403/付费/仅摘要）时：不要编。卡片里如实写"该报告本机不可达，以下依据官方通报＋附录 B 页面摘要"，并且只写能核的部分。

## 五、范例

`_spec/范例卡片-哥伦比号.md`——这是本书已定稿的卡片，照着它的密度与句法写。它 2,048 汉字，略短于目标，你写到 3,000 上下。

## 六、交付

- 直接把卡片写回本章文件的 §3（`## 3 现场` 或 `## 3 四个领域的形态`）。
- 原文里这段压缩案例的文字要**被卡片吸收**，不保留原压缩版，避免重复。同章其他段落一个字不动。
- 另写一份 `_evidence/<编号>.md`：写清你读了哪份文件、页码、以及卡片里每个数字的出处行原文（英文照录）。
