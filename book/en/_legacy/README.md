# Failure: A Field Guide to Organizational Collapse

A reference book on how organizations fail. The raw material is primary investigation reports; the method is case cards indexed by mechanism. 42 chapters, 14 domain profiles, 5 appendices.

## The Reader's Contract

1. Every chapter opens with three lines: what it covers, when to return to it, how long it takes.
2. Every chapter ends not with a summary but with five self-check questions. If you cannot answer them about your own situation, the mechanism described is operating on you right now.
3. Every case stops at the decision point. The reader judges first, then turns the page.
4. No moralising. Only structure — never "should."
